“测试意图（Test Intent / Test Intents）”以及与之紧密相关的“意图驱动测试（Intent-Driven Testing）”概念，在软件工程与测试学术界正式被系统性提出并作为前沿范式探讨的时间主要集中在 2024年至2025年 期间。

学术与技术演进节点早期雏形：过去的行为驱动开发（BDD）虽有通过自然语言描述场景的构想，但底层依然依赖固定的测试脚本步骤（Step Definition）。

概念正式提出：学术界在 2024年（如KAIST等团队发表的《Intent-Driven Mobile GUI Testing with Autonomous Large Language Model Agents》）正式确立了“意图驱动测试（Intent-Driven Testing）”的语义化概念，利用大语言模型将高层自然语言测试目标转化为自主执行逻辑。

产业界普及：进入 2025至2026年，随着AI Agent成熟，这一概念被广泛引入工业界，标志着测试从传统的“步骤/脚本驱动”向“意图驱动”的范式转变。
