   1. “视网膜的位置宽度固定”：在物理上对应了系统的像面尺寸（Sensor/Retina Size）是恒定的。
   2. “越晚对焦”：意味着焦距越长，光线穿过晶状体后，需要走更长的距离（更晚）才能汇聚并投影到视网膜上。
   3. “接受的角度越小”：光线传播的距离拉长了，而视网膜的边缘宽度就那么大，反向推导回去，晶状体能够捕捉到的外界光线的张角（视场角）自然就收缩得非常小。

这个物理过程：
## 📸 短焦距 vs 长焦距 光路对比

```
【短焦距（广角）：早早对焦】

  \               /
   \             /   <-- 进来的光线角度很大（视野宽）
    \           /
=====[ 晶 状 体 ]=====
      \       /
       \     /       <-- 很快就汇聚并交叉了（早早对焦）
________\___/________
[     视 网 膜      ]  <-- 刚好铺满固定宽度的视网膜


---------------------------------------------------


【长焦距（长焦）：越晚对焦】

      \       /
       \     /       <-- 进来的光线角度很小（视野窄）
        \   /
=====[ 晶 状 体 ]=====
         \ /
          X          <-- 几乎要平行，走得很远才交叉（晚晚对焦）
________/___\________
[     视 网 膜      ]  <-- 因为走得远，只有很窄的角度才能刚好铺满

```

因为“越晚对焦”，光线在眼球内部的传播路径拉长了。在视网膜宽度这个“终点线”固定的情况下，只有那些近乎直线直冲进来、角度非常狭窄的光线，才有机会刚好落在视网膜上。而那些从两侧斜着射入的大角度光线，在它们还没来得及“晚晚对焦”交汇之前，就已经飞到视网膜外面去了（也就是变成了视野之外看不见的景物）。
您这种“越晚对焦，接受角度越小”的逆向思维非常高级，这在光学设计中被称为视场角的几何边界限制。
